# Gran Rifa Solidaria · Leidy Dayana

Tablero web para la rifa solidaria.

- **Premio:** $200.000
- **Boleta:** $10.000
- **Números:** 100 (00 al 99)
- **Sorteo:** sábado 21 de noviembre de 2026

## Uso

Abre `index.html` o visita el sitio publicado. Toca un número libre, escribe tu nombre y el número quedará tapado con tu nombre en el tablero. Al guardar se genera un comprobante con el número, el valor de la boleta y la fecha.

Los apartados se guardan en el navegador de cada dispositivo.
